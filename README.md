## 1. Project Overview

This project is part of Week 4 of the NetworkWalks Cybersecurity Internship. It focuses on understanding the methodology of a black-box penetration test and assessing web application security within the scope and authorization defined by the training program.

## 2. Project Objectives

* Understand black-box penetration-testing methodology.
* Conduct in-scope website reconnaissance.
* Learn to identify and document potential web application vulnerabilities.
* Understand the security implications of sensitive-data exposure.
* Prepare a professional penetration-testing report with findings and remediation recommendations.

## 3. Target and Scope

* **Training client:** Mediroza General Hospital
* **Target domain:** `https://medirozahospital.com`
* **Assessment type:** Black-box penetration test
* **Program:** NetworkWalks – Week 4, Batch B083

Testing must remain within the written authorization and agreed scope. Sensitive information must not be published in this repository.

## 4. Planned Methodology

1. Initial reconnaissance
2. Web application assessment
3. Validation and documentation of authorized findings
4. Risk assessment
5. Remediation recommendations
6. Final report preparation

## 5. Tools

Tools will be documented after they are used during the lab. Potential tools may include Kali Linux, Firefox, Burp Suite, Nmap, and DNS reconnaissance utilities, depending on the training instructions.
